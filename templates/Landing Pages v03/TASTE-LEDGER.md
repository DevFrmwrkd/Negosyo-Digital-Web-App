# TASTE-LEDGER

Append-only. Newest entries at the bottom of each list.

## LIKE ✅

- **2026-07-09 — Manifestos honored end-to-end.** why: each of the 8 pages traces every decision (font pair, palette, hero architecture, texture) back to its one-line manifesto; nothing is default.
- **2026-07-09 — One signature interaction per page, CSS-only.** why: rolling specials ticker (01), chevron-sweep CTA (02), rotating FAQ plus-marker (03), jab-skew CTA (04), highlighter sweep (05), self-drawing dashed lines (06), rubber-stamp tilt cards (07), rising steam (08). Each is small, on-brand, and needs no JS to read the page.
- **2026-07-09 — Art-directed placeholders.** why: every image slot is a designed plate in the page's own language (ember duotone, halftone paste-up, blueprint fig. frames, deco arches) with descriptive alt + `<!-- IMG -->` note. No grey boxes anywhere.
- **2026-07-09 — Answer-first copy.** why: first about-paragraph on every page is a self-contained 2-sentence "what is this and who is it for"; every FAQ answer front-loads the answer in sentence one. Good for readers and for GEO.
- **2026-07-09 — Distinct hero architectures.** why: full-bleed duotone + ticker / torn job-sheet split / asymmetric editorial pair / vertical poster + full-bleed plate / notebook two-column / blueprint annotated split / broadsheet masthead / arched triptych — no two share a skeleton.
- **2026-07-09 — GBP-bound volatile data.** why: rating, review count, and hours are commented `data-gbp` slots on every page; nothing on the page can go stale.
- **2026-07-09 — Business-true texture.** why: PH-specific details (uling from Bulacan, TESDA certs, casa-warranty law, ABAP pedigree, UPCAT/ACET, canvass-by-Messenger, pasalubong boxes) make each page read like a real operator wrote it.

## AVOID ❌

- **2026-07-09 — Run-on SEO headlines.** why: "Name: long description in City" reads like a robot; SEO belongs in `<title>`, meta, schema — the visible h1 must be crafted.
- **2026-07-09 — Empty grey boxes as image placeholders.** why: they read as unfinished and get the whole deliverable rejected; placeholders must carry the page's art direction.
- **2026-07-09 — Template-y sameness.** why: eight buckets with the same grid recolored is one design, not eight; every bucket deserves its own hero skeleton and type system.
- **2026-07-09 — Timid flat styling that reads like 1995.** why: no texture, no scale, no hierarchy signals "nobody designed this"; boldness is part of the brief.
- **2026-07-09 — Volatile data hardcoded.** why: prices, promos, staff names, star ratings and hours go stale and break trust — bind them (GBP slots) or omit them.
- **2026-07-09 — Emoji as icon system.** why: reads as filler; one deliberate glyph in a brand's own language is fine, a row of emoji bullets is not. (Kept to a single Messenger-pill glyph where used.)
- **2026-07-09 — Identical three-card grids as the answer to everything.** why: card grids are a tool, not a reflex — service sections here vary between ledger rows, spec sheets, classified columns, and stamped cards.
